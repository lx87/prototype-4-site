# Инструкция по запуску проекта

## Быстрый старт

1. **Установите зависимости:**

   ```bash
   npm install
   ```

2. **Запустите dev-сервер:**

   ```bash
   npm run dev
   ```

3. **Откройте браузер:**
   Перейдите по адресу `http://localhost:5173`

## Структура сайта

### Основные страницы:

- **Главная** (`/`) - Hero Block, популярные товары, категории, преимущества
- **Каталог** (`/catalog`) - Все товары с фильтрацией
- **Товар** (`/product/:id`) - Детальная страница товара с вариантами
- **Корзина** (`/cart`) - Список товаров в корзине
- **Оформление заказа** (`/order`) - Форма заказа
- **Успешный заказ** (`/order/success`) - Подтверждение заказа

### Особенности реализации:

1. **Диван с вариантами** - товар ID: 1

   - 8 вариантов (цвет, размер, материал)
   - Подробная карточка с выбором характеристик

2. **Фильтрация в каталоге:**

   - По категориям
   - По цене (диапазон)
   - Сортировка (популярность, цена, название)
   - Поиск по названию и описанию

3. **Анимации:**

   - Hero Block с анимированной кнопкой
   - Появление элементов при скролле
   - Плавные переходы при наведении

4. **Адаптивность:**
   - Мобильная версия с гамбургер-меню
   - Адаптивная сетка товаров
   - Оптимизация для планшетов

## Сборка для продакшена

```bash
npm run build
```

Файлы будут в папке `dist/`

## Тестирование функциональности

1. **Добавление в корзину:**

   - С главной страницы
   - Из каталога
   - Со страницы товара

2. **Варианты товара:**

   - Откройте товар "Диван Комфорт Плюс"
   - Выберите цвет, размер, материал
   - Цена обновляется автоматически

3. **Корзина:**

   - Изменение количества
   - Удаление товаров
   - Итоговая сумма

4. **Оформление заказа:**
   - Заполните форму
   - Выберите способ доставки
   - Отправьте заказ

## Технические детали

- **State Management:** React Context API для корзины
- **Роутинг:** React Router DOM
- **Анимации:** Framer Motion
- **Стилизация:** CSS Modules
- **Типизация:** TypeScript

## Примечания

- Все изображения используют Unsplash (placeholder)
- Данные товаров хранятся в `src/data/products.ts`
- Корзина сохраняется только в памяти (при перезагрузке очищается)
- Форма заказа имитирует отправку (в консоли браузера)
