# Интернет-магазин ShopStore

Полнофункциональный сайт-магазин, разработанный на React + TypeScript.

## Особенности

- ✅ Адаптивный дизайн для всех устройств
- ✅ Хедер и Футер на всех страницах
- ✅ Главная страница с Hero Block и анимациями
- ✅ Каталог товаров с фильтрацией
- ✅ Детальные карточки товаров с вариантами
- ✅ Корзина покупок
- ✅ Форма оформления заказа
- ✅ Анимации при скролле и наведении

## Технологии

- React 18
- TypeScript
- React Router DOM
- Framer Motion (анимации)
- Vite (сборщик)

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите dev-сервер:

```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`

## Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Header/         # Хедер с навигацией и корзиной
│   ├── Footer/         # Футер с контактами и картой
│   └── ProductCard/    # Карточка товара
├── pages/              # Страницы приложения
│   ├── Home/           # Главная страница
│   ├── Catalog/        # Каталог товаров
│   ├── ProductPage/    # Страница товара
│   ├── Cart/           # Корзина
│   ├── OrderForm/      # Форма заказа
│   └── OrderSuccess/   # Страница успешного заказа
├── context/            # React Context
│   └── CartContext.tsx # Контекст корзины
├── data/               # Данные
│   └── products.ts     # Товары и категории
└── types/              # TypeScript типы
    └── index.ts
```

## Функциональность

### Хедер

- Логотип магазина
- Навигационное меню
- Поиск товаров
- Корзина с счетчиком товаров
- Адаптивное мобильное меню

### Главная страница

- Hero Block с анимированной кнопкой
- Популярные товары
- Категории товаров
- Блок преимуществ магазина

### Каталог

- Фильтрация по категориям
- Фильтрация по цене
- Сортировка (популярность, цена, название)
- Поиск товаров
- Адаптивная сетка товаров

### Карточка товара

- Крупные изображения товара
- Варианты товара (цвет, размер, материал)
- Выбор количества
- Добавление в корзину
- Блок "С этим товаром часто покупают"

### Корзина

- Список товаров
- Изменение количества
- Удаление товаров
- Итоговая сумма
- Оформление заказа

### Форма заказа

- Контактная информация
- Выбор способа доставки
- Валидация полей
- Итоговая информация о заказе

## Адаптивность

Сайт полностью адаптирован для:

- Десктоп (1200px+)
- Планшет (768px - 1199px)
- Мобильные устройства (до 767px)

## Анимации

Использованы анимации:

- Появление элементов при скролле
- Плавные переходы при наведении
- Анимированная кнопка в Hero Block
- Параллакс эффекты

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.
